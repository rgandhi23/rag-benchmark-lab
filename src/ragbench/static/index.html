Understand the system

How one question travels through the pipeline

The interface is intentionally transparent: every answer can be traced back to ranked source chunks and every configuration can be benchmarked.

Chunk

Documents are split into overlapping word windows so small passages can be retrieved.

Embed

Each chunk and question becomes a numeric vector representing its terms or meaning.

Search

Cosine similarity ranks stored vectors and returns the top K evidence chunks.

Generate

The answer generator receives only the question and retrieved evidence, then produces citations.

Evaluate

Known relevant documents are compared with the ranking and the run is saved to SQLite.

Hit Rate@KDid the result set contain at least one relevant document?
Precision@KWhat fraction of returned documents were relevant?
Recall@KWhat fraction of all relevant documents were retrieved?
MRRHow early did the first relevant document appear in the ranking?
